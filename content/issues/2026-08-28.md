本週 AI Security 閱讀清單已完成。公開來源掃描與 Weekly AI Report 去重、交叉查核後，共入選 **9 項：深入審閱 4 項、選讀 5 項**。

最高優先為 **TrustShiftProbe**：它揭露 MCP Server 可先正常運作、建立信任後再切換為惡意行為，顯示上線前掃描無法取代持續性 runtime 監控。

## 本週優先閱讀排序

### 1. TrustShiftProbe：MCP Server 階段式信任攻擊

- **發布日期／作者**：2026-08-24；Mehrdad Rostamzadeh、Sidhant Narula、Mohammad Ghasemigol、Daniel Takabi
- **原始來源**：[arXiv 2608.23763](https://arxiv.org/abs/2608.23763)
- **核心發現**：惡意 MCP Server 可先經歷 benign conditioning，再於信任臨界點切換成 schema-valid 操控、資料外洩或服務破壞。9 種攻擊變體的平均攻擊成功率為 **69.5%**；SHIELD runtime 防禦將其降至 **42.7%**，仍留下顯著殘餘風險。
- **製造業關聯**：適用於串接 PLM、ERP、原始碼儲存庫、採購、工單與 OT 資料的 AI Agent。供應商通過上線前檢查，不代表後續 MCP 行為可信。
- **判定：深入審閱**。本次報告截點後新發布，直接改變 Agent/MCP 威脅模型；但仍是未經同儕審查的受控實驗。

### 2. ICS Cybersecurity Datasets：ICS 資料集結構性缺口

- **發布日期／作者**：2026-08-25；Konstantinos E. Kampourakis 等 7 人
- **原始來源**：[arXiv 2608.24757](https://arxiv.org/abs/2608.24757)
- **核心發現**：PRISMA-guided meta-review 彙整 18 項研究、83 個 ICS 資料集；**85.5%** 聚焦末期 OT disruption、只有 **8.4%** 涵蓋跨階段 IT/OT 攻擊、實際營運來源僅 **15.7%**，Purdue Level 0 證據幾乎缺席；沒有研究採 streaming evaluation，僅 2 項符合其重現性條件。
- **製造業關聯**：不能因 AI/ML IDS 在 SWaT、Edge-IIoT 等資料集取得高 F1-score，就推定能偵測真實產線橫向移動或 field-device 攻擊。
- **判定：深入審閱**。是本週製造／OT 關聯度最高的新研究，可直接用來強化 SIEM/XDR/OT AI PoC 驗收條件。

### 3. REDAgentBench：可執行的 AI Agent 紅隊量測

- **發布日期／作者**：2026-08-11；Zixing Chen 等
- **原始來源**：[arXiv 2608.10669](https://arxiv.org/abs/2608.10669)
- **核心發現**：1,661 個案例、5 種服務面、6 個模型及 3 種 agent harness，巨集平均攻擊成功率 **65.69%**；近五分之一已確認違規發生於 Agent 已辨識風險之後。Training-free policy reminder 在 matched replay 中降低超過 70 個百分點。
- **製造業關聯**：AI 驗收應以沙箱中的實際狀態變更、service receipt、檔案差異與 API 副作用為證據，不能只檢查模型文字回答。
- **判定：深入審閱**。適合改寫為企業 AI Agent 上線前紅隊與驗收 SOP；數字僅代表基準環境，不是生產事故率。

### 4. Foundation-Model-Powered Embodied Agents Security Survey

- **發布日期／作者**：2026-08-17；Jiawei Liu 等
- **原始來源**：[arXiv 2608.16843](https://arxiv.org/abs/2608.16843)
- **核心發現**：以 first-compromised-trust-boundary 方法劃分 5 層、12 個攻擊面，彙整 58 筆攻擊與61 筆防禦紀錄。長期記憶、world-state integrity、middleware/networking 與 multi-agent trust 仍屬明顯研究缺口。
- **製造業關聯**：可用於 AGV／AMR、機器手臂、AI 視覺檢測、Digital Twin 與 AI 控制決策的 OT×AI 威脅建模。
- **判定：深入審閱**。能補強 IEC 62443 架構中「AI 決策如何傳導成實體動作」的分析空白；屬綜述而非新攻擊實驗。

### 5. Bounded Agents：多代理委派安全

- **發布日期／作者**：2026-08-16；Xabier Muruaga
- **原始來源**：[arXiv 2608.15888](https://arxiv.org/abs/2608.15888)
- **核心發現**：Agentic Principal Chain 將權限範圍、預算與先前動作納入六項授權檢查。3,154 個評估案例中，AgentDojo 資料外洩由 75–100% 降至 0%，並攔下 544 個 InjecAgent 外洩案例；但部分設定使任務效用下降 8.6～13.9 個百分點。
- **製造業關聯**：適用於多代理採購、供應商審查、程式修補與跨系統工單；應在模型外部強制執行 capability budget、scope attenuation 與組合動作限制。
- **判定：選讀**。量化完整且有公開實作，但仍是單一作者預印本，需在企業流程中重測效用損失。

### 6. OWASP Top 10 for LLM Applications 2026＋事件資料分析

- **發布日期／機構**：官方頁 2026-08-03；OWASP GenAI Security Project
- **原始來源**：[OWASP 官方頁](https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/)、[事件資料分析](https://arxiv.org/abs/2608.19266)
- **核心發現**：最終排序為 Prompt Injection、Sensitive Information Disclosure、Excessive Agency、Supply Chain、Data and Model Poisoning、Unbounded Consumption、Misinformation、Hidden Context Exposure、Vector and Embedding Weaknesses、Improper Output Handling。排序採 **75% 專家意見＋25% 事件資料**；事件分析使用 7,714 筆快照、6,639 筆分類資料，但專家與事件排序的 Cohen’s κ 約 0.20，區間跨越零。
- **製造業關聯**：應將 LLM02、LLM03、LLM04、LLM08 分別對應 DLP、Agent 權限控制、AI 供應鏈與 RAG／隱藏政策資訊保護。
- **判定：選讀**。適合作為控制完整性清單，不宜把排序直接解讀成企業事故發生率。

### 7. NIST IR 8611：m-NGAC 資料庫細粒度存取控制

- **發布日期／機構**：2026-08-27；NIST
- **原始來源**：[NIST IR 8611](https://csrc.nist.gov/pubs/ir/8611/final)
- **核心發現**：把 ANSI/INCITS NGAC 直接嵌入資料庫，在 individual-column data 層強制執行集中式細粒度政策，不依賴查詢工具自身是否正確套用控制。
- **製造業關聯**：可作為 RAG、AI data lake、PLM BOM、客戶設計資料與訓練資料的後端 enforcement 參考；能補足僅靠前端 DLP 或 Agent prompt policy 的不足。
- **判定：選讀**。本週新發布的 NIST Final，但並非 AI 專屬，也未提供企業規模量化成效。

### 8. NIST IR 8613：Multi-Cloud Security and Compliance

- **發布日期／機構**：2026-08-21；NIST
- **原始來源**：[NIST IR 8613 IPD](https://csrc.nist.gov/pubs/ir/8613/ipd)
- **核心發現**：整理 23 個多雲架構挑戰，最集中於 IAM、telemetry/logging、configuration/change management、data protection 與 compliance/authorization。意見徵集至 **2026-10-05**。
- **製造業關聯**：適合用來檢查臺灣、美國、墨西哥、捷克與中國隔離環境的 AI/DSPM 可視性、資料邊界及控制一致性。
- **判定：選讀**。官方且具多雲資料保護價值，但不是 AI Security 專屬文件。

### 9. NIST SP 1353：使用 AI 協助 CSF 2.0 分析與報告

- **發布日期／機構**：2026-08-19；NIST
- **原始來源**：[NIST SP 1353 IPD](https://csrc.nist.gov/pubs/sp/1353/ipd)
- **核心發現**：提供 Governance Review、Current State Profile、Target State Profile 三種示範情境及結構化 prompts；意見徵集至 **2026-10-15**。
- **製造業關聯**：可支援 AI 輔助稽核證據整理與 CSF 差距分析，但內部政策、訪談與證據輸入前仍須分類、去識別化及限制保留。
- **判定：選讀**。NIST 明確表示它不是 AI 安全最佳實務，也不是保證性稽核方法，不能把生成結果直接視為稽核證據。
